# KanastaScore Privacy Information

KanastaScore is an offline score-management application.

## Stored data

The application stores match names, team and player names, round scores, settings, and statistics locally on the Android device.

## Internet access

KanastaScore does not request the Android internet permission and does not upload match data to an external service.

## Backup and sharing

Backup export, backup import, and result sharing occur only when the user explicitly selects those actions. Exported files and shared images are handled through Android's document and sharing interfaces.

## Data removal

Users can delete stored matches from the application, clear all application data, or uninstall KanastaScore.
